# Price-monitoring

## Charts

1. Wszystkie karty - python plot_prices.py
1. Jedna pozycja - python plot_prices.py --id rtx4070-asus-dual
1. Wybrane pozycje - python plot_prices.py --id a b c
1. Wszystkie 4070 z 12 GB - python plot_prices.py --model 4070 --vram 12
1. Jeden sklep, ostatni miesiąc - python plot_prices.py --shop x-kom --days 30
1. Otwórz okno zamiast tylko zapisu - python plot_prices.py --model 4070 --show
